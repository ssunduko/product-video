# Grammar tour (sample-app)

An example video that exercises every trace step op against the local Express
app in `sample-app/`, so the pipeline can be tried without a live account.

| | |
|---|---|
| Target | `local-app` (`cd sample-app && npm start`) |
| Videos | `videos/grammar-tour.json` |
| Trace | `scenarios/grammar-tour.trace.json` |

Use it to check a pipeline change end to end before recording against a live
app.
